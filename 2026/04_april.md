【一言で言うと】<br>
SQLクライアントとは、DBを触ることができるUIである<br>
セッションとは、サーバ側に保存されるユーザごとの情報のこと<br>
Cookieとは、ブラウザに保存される小さなデータのこと<br>
CRUDとは、データ操作の最小単位で、様々なアプリで採用されている<br>
非同期処理とは、処理の完了を待たずに、次の処理へ進む仕組みのこと<br>
FulePHPはリクエスト⇒Controller⇒Model⇒View⇒レスポンスというながれでうごく<br>

【学び・Why】<br>
ログインIDをサーバが発行して、Cookieに保存される。次のリクエストでは、Cookieが送信され、サーバ側でCookieから来たログインIDをもとにユーザを特定できる<br>
Cookieは、改ざんされるリスクがあるので、重要な情報はサーバ側のセッションで保存しておく。Cookieは鍵である。<br>
CRUDとは、Create、Read、Update、Deleteの４つである。これに分けることで、責務が明確になること、バグの切り分けが簡単なこと、チームで開発分担しやすいというメリットがある<br>
同期処理では、処理が終わるまで次に進まないので、ユーザは待たされることになる。そのため、非同期処理にして、ローディング表示を行うことで、ストレス、離脱率が下がってくれる。<br>
JSでいう、Promise、async,awaitを習っていたので、復習で済んだ。<br>
層ごとに区切ることでどこでエラーが起きているか、分かりやすい。<br>

コンストラクタ関数とは，new演算子を使って同じ構造を持つオブジェクトを複数生成するための雛形となる関数

【学び・Why】<br>
大学の授業，クリーンコードの講座でclassの使い方を学んでいたので，どちらもそこまで難しくなかった<br>
何度も，同じ関数を呼び出すことは無駄なこと，初期値の設定が容易だからコンストラクタ関数を使っている<br>

### 4月4日
【やったこと】<br>
React学習:'Reactとは'の学習<br>
【一言で言うと】<br>
Reactとは、UIを構築するためのJavaScriptライブラリであり、状態に応じて画面を自動的に更新する宣言的UIが特徴です。<br>
【学び・Why】<br>
従来のjQueryなどはDOMを直接操作するため、状態管理が複雑になりやすい<br>
Reactは状態（state）を中心にUIを構築するため、コードの可読性・保守性が高い<br>
仮想DOMにより、変更差分のみを更新するためパフォーマンスが良い<br>
コンポーネント単位で分割できるため、再利用性が高くチーム開発に向いている<br>

【一言で言うと】<br>
XHRは最近は使われておらないが，モダンなfetch,Axiosの基本となる<br>
fetchは，returnでjsonを毎回返さなければいけない<br>
Axiosは，それだけでjsonを返してくれるので現代でもっとも使われる<br>

【コード】<br>
const getStarWarsPerson = async (id) => {<br>
    try {<br>
        const res = await axios.get(`https://swapi.dev/api/people/${id}/`);<br>
        console.log(res.data);<br>
    } catch (e) {<br>
        console.log('ERROR', e)<br>
    }<br>
}<br>

【学び・Why】<br>
Axiosを使うことで，try,catchによりerrorを知らせることもできる<br>
自動でJsonになるので，記述量が減る<br>
